# knowledge_graph/ — Legacy documentation

This directory contains documentation from the pre-RDF phase of the project
(ClimaternaKG, Neo4j property graph, April 2026). Retained for historical
reference only. Does not reflect the current PerinatalKG v0.3.0 architecture.

The current system uses RDF/OWL 2. See:
- ontology/perinatalkg_full.ttl — OWL 2 ontology (v0.3.0)
- ontology/perinatalkg-shapes.ttl — SHACL validation shapes
- etl/07_batch_rdf_pipeline.py — RDF conversion pipeline
- examples/ — SPARQL query examples
